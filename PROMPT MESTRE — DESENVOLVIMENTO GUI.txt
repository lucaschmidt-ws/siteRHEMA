1. DESCRIÇÃO DO PROJETO
O que eu quero construir:
[Quero desenvolver um projeto completo de programação para a marca RHEMA, uma marca de roupas streetwear cristãs.

A ideia é criar uma loja virtual moderna, profissional, responsiva e funcional, começando pelo front-end e evoluindo posteriormente para back-end e banco de dados.

A RHEMA terá uma identidade visual minimalista, sofisticada e urbana, com referências cristãs. O site deverá apresentar a marca e permitir que o usuário navegue pelas diferentes coleções de roupas.

As principais categorias inicialmente serão:
- Básicos
- Oversize
- Streetwear
- Sporting

Quero que o site tenha uma página inicial apresentando a RHEMA, suas coleções e sua identidade. Também quero um catálogo de produtos, páginas individuais para cada produto, informações como nome, descrição, preço, tamanhos, cores e imagens.

No desenvolvimento futuro, quero implementar:
- Busca de produtos;
- Filtros por categoria, tamanho e outros atributos;
- Carrinho de compras;
- Sistema de cadastro e login;
- Área do usuário;
- Lista de pedidos;
- Controle de produtos;
- Banco de dados;
- Integração entre front-end e back-end;
- Sistema de pedidos;
- Possibilidade de pagamento;
- Painel administrativo;
- Responsividade para celular, tablet e computador;
- Segurança e validação dos dados;
- Publicação do sistema na internet.

No início, quero trabalhar principalmente com HTML, CSS e JavaScript para aprender a construir o front-end. Depois quero evoluir para JavaScript mais avançado, lógica de programação, back-end, APIs e banco de dados.

Um dos principais objetivos desse projeto é meu aprendizado. Estou começando na programação e quero utilizar a RHEMA como um projeto real para aprender. A inteligência artificial pode ser utilizada como ferramenta de apoio, mas quero que cada etapa seja explicada para que eu consiga entender o código, a lógica e a estrutura do sistema, em vez de simplesmente copiar códigos prontos.

Quero que o desenvolvimento seja feito de forma gradual, começando por uma versão simples e funcional e evoluindo até uma loja virtual completa.

O objetivo final é transformar a RHEMA em um e-commerce real, com uma boa experiência de usuário, identidade visual profissional e estrutura técnica que permita continuar adicionando funcionalidades no futuro.

Durante o desenvolvimento, explique o que está sendo feito, por que está sendo feito e como cada parte do código funciona. Priorize meu aprendizado e minha autonomia como programador.]
